## Design decisions

- Main input is thumb drag and automatic basic attacks. A large optional special button can become automatic at mastery rank 5.
- Verdant Verge selects a Waylight Moth escort or a Seedheart defense each run. The escort moves when the player stays close and clears enemies; the Seedheart charges inside its ring only while nearby foes are cleared. Both have a halfway ambush. Quarry selects a pump-to-forge assault or a timed three-flask delivery from the coolant spring. Moonfen selects the bloom-to-altar rite or a three-catch Moonflame pursuit across the map. Route choices use separate seed bits, and existing saved objectives determine their own route when resumed. Each region then has a gate encounter and an optional shrine chain. The mission card shows distinct art, action, and progress for each task. Auto attacks hit nearby enemies before attackable objects; splash attacks and specials can damage both. Ambient waves stop when the gatekeeper appears, leaving its phase reinforcements as the encounter pressure.
- The Warden defaults to an axe, Ranger to thorns, and Ember to a staff. Axe and Sunbow are available from the first run; further weapons unlock through progress. Every run starts with a selected primary and support weapon. Mastery rank 4 starts with a third slot; a later relic can open it otherwise. Tapping an equipped weapon fires its named command when a target is in range: axe sweeps and knocks back, thorns fan out and root, bow snipes at long range, and staff leaves burning ground. The slot also focuses that weapon for 25% more automatic damage and a weapon-specific attack change while other equipped weapons deal 10% less damage. Each slot has an independent eight-second command recharge.
- The axe cleaves clusters, thorns pierce one aligned foe, the Sunbow can land critical hits, and the staff leaves a short burn. Warden starts tougher and uses Whirlwind for knockback and healing; Ranger's volley reaches distant foes; Ember's nova ignites survivors. Burn state survives run resume.
- Weapon rank II and III change attack behavior: wider axe cleaves and knockback, two then three thorn pierces, higher bow crit chance and ricochet, stronger and wider staff burns. At rank II, each weapon gets a two-way technique offer with persistent attack effects. Loadout slots show the current trait, command charge, and run damage; the result screen compares weapon output. Technique, command charge, burn attribution, and damage counters survive run resume.
- Firing a different weapon command within four seconds triggers one of six pair resonances. Axe + thorns root a ring of foes; axe + bow strike elites harder; axe + staff push and burn; thorns + bow strike five targets; thorns + staff root and burn; bow + staff detonate a wide burn. Camp selection previews the pair, the HUD names the second slot and countdown, and the run report counts successful chains. The remaining chain window survives run resume.
- Ember Quarry has optional attackable vents that warn before short eruptions. Moonfen's mist blooms slow movement inside their rings and are required for the altar sequence. Their object state survives run resume.
- Each region has two optional attackable terrain fields. Verge brambles slow both sides, Quarry ore reduces damage taken by nearby foes, and Moonfen moonstones hasten them. Tap a field (or press F) to prioritize it over foes; breaking brambles roots nearby enemies, ore blasts them, and moonstone discharges while granting a six-second speed boost. Each drops a stat cache and refills all weapon commands, tying terrain choices to the loadout. The target mark, rooted enemies, temporary boost, and field state survive run resume.
- The Briar King periodically marks the ground ahead of the hero's current movement. A visible ring gives time to change direction before the strike lands; later phases widen the strike and shorten its cooldown. The marker and countdown survive run resume.
- Quarry and Moonfen wisps aim narrow marked lanes before firing. Their warning, cooldown, and target survive run resume. Late in each region a Wild Surge increases wave frequency and wisp appearances; the run clock labels the change. The result screen records lance hits and evasions.
- Browser storage remains local. Migrate `grovebound-progress-v1` to `grovebound-progress-v2` without consuming old seeds or removing the Thorn Dart unlock.
- Keep Grovebound and Planetfall separate. Build `dsschiff/games` as a later public Pages hub; do not link a private Planetfall URL from it.

## Release gate

Run `npm test` and the production build; stage the Pages build into `docs/`; commit source and `docs/` together; push; verify the live URL and commit; record findings in `WORKLOG.md`.

## Next unfinished increment

Milestone 3 systems are implemented, including all regions, a phased boss, victory, and exact local resume. Every region now has two mission routes. Runs start with two weapons; each slot has a distinct active command, and rank II offers a technique fork. Six pair resonances reward command timing and make the starting pair consequential. Each hero now has an illustrated signature action frame; the Waylight, Seedheart, Moonflame, and mist blooms move independently. Quarry and Moonfen add aimed ranged danger and late Wild Surges. Fields can be targeted for distinct combat bursts and a command refill. The next priorities are more varied mission structures and enemy roles, human balance feedback on command timing and visual clarity, and a real Android Chrome performance and assistive-technology pass. The public games hub is live; keyboard navigation and dialog semantics have been checked in a desktop browser at phone size.
